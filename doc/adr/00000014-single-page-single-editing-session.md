# 只有一個 HTML 入口，同時只有一個編輯階段

> 服務：不變式 2

- **Date:** 2026-09-02
- **Status:** Accepted

## Context

多人或多分頁同時編輯會產生「兩個人都以為自己在編輯」的窗口，
正在編輯的內容可能靜默遺失。

## Decision

只有一個 HTML 檔，所有視圖在同一頁內切換。主畫面是核心，所有子視圖完成後
回到主畫面；子視圖之間沒有直接跳轉。

頁面載入時向後端要求編輯階段；已被占用時顯示唯讀模式並指名持有者、email
與開始時間。正常關閉時主動釋放，異常中斷靠續期逾時釋放。**不提供強制接管。**

## Alternatives

- **多頁面**：每次切換都要重新取得狀態；「切換頁面」與「開了第二個分頁」難以分辨，
  鎖的判定會變複雜。
- **允許強制接管**：產生兩人同時編輯的窗口，正是要避免的失效類型。
- **允許多人同時編輯 + 合併**：需要衝突解決 UI，複雜度遠超過本專案需求。
- **子視圖之間可直接跳轉**：技術上可行，但會讓「我現在在看哪一份」難以追蹤。

## Consequences

- 使用者可能需要等待逾時。過程明確：持有者知道自己逾時，接手者知道前一位已離開。
- 部署模式下閒置 10 分鐘自動退出並釋放階段（開發模式不逾時）。
