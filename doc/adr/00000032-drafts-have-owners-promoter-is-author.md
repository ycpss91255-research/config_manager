# 草稿有主人；進版者是紀錄作者，草稿作者寫進內文

> 服務：不變式 2（絕不靜默失敗）、不變式 4（預設值落向安全）

- **Date:** 2026-10-31
- **Status:** Accepted
- **Relates to:** ADR-00000014（單一編輯階段）、ADR-00000022（草稿層）、ADR-00000020（身分是自我宣告）；人工驗收 F22、F7（第 5 批）

## Context

草稿是整個服務共用的一份、存在編輯階段的伺服器端狀態（ADR-00000022），**不記是誰存的**。
階段在兩種情況下結束而草稿留下：正常關頁／重新整理（釋放，不清）；於是下一個取得階段的人
——可能是別人——會接手這些草稿，並以自己的名字進版（F22，10/20 讀程式發現）。另一方面，
**續期逾時**（持有分頁 150 秒沒續期：筆電睡眠、斷網）會回收階段並**清掉全部草稿**；人工驗收
期間 Mac 合蓋睡眠發生五次，兩次真的清掉了未進版的工作（F7）。

兩者都在回答同一題：草稿什麼時候該消失、消失時誰該知道、留下時算誰的。

## Decision

1. **每份草稿記主人**：`saved_by`（最後成功儲存者）與 `touched_by`（所有成功儲存過的人，
   依首次順序、去重）。「同一人」以**姓名＋email＋瀏覽器票**判定——系統沒有認證
   （ADR-00000020），不把同名同 email 自動當成同一個人；票只在後端記、不回給頁面、不寫進
   紀錄、不出現在證據裡。只有成功儲存算參與（驗證失敗、取消、只是開著看不算）。
2. **續期逾時只回收階段，不清草稿**。草稿留給下一個取得者（多半是同一個人醒來重新整理），
   取得時被告知「接手了〈誰〉存的 N 份」。閒置逾時（部署模式）與退出**仍清除**並逐人提示——
   這兩個是人明確離開；續期逾時是分頁斷了，人不一定走了。
3. **進版紀錄的 author 是進版者**（真正按下、對這批負責的人）。草稿由別人存時，那一筆紀錄
   的內文逐行註明 `drafted-by: 姓名 <email>`（同名不同票時加「（另一個瀏覽器）」，不寫票）；
   自己存自己進版的不寫。歷史介面在進版者旁另顯示「含〈誰〉存的草稿」。
4. **這批草稿的參與者含別人時，進版先經確認**（列出誰參與幾份、不重複總數、說明紀錄作者是你）；
   取消不改任何東西；確認期間草稿變了就拒絕、重新確認。全是自己的照舊直接進版。
5. **退出仍清掉目前全部共用草稿**（含接手來的）——階段只有一個，退出就是它結束；只是確認框與
   退出後的說明**逐人列**（同一份多人參與會重複計入，另列不重複總數）。唯讀者退出不碰草稿（現狀）。
6. **服務重啟草稿消失**維持（記憶體；U40 明寫不要求保留），訊息說清楚，不做持久化。

本決定**不**處理部署模式的閒置逾時：合蓋超過閒置逾時（預設 10 分鐘）仍會清草稿。

## Alternatives

- **任何階段結束都清草稿（含關頁／重新整理）**：規則最簡單，但重新整理就丟工作——F28 之後
  「重新整理頁面以重新取得」是正式的恢復手段，不能連草稿一起丟。
- **換手時強迫選「接手」或「捨棄」**：多一個流程與對話框；主人標示＋進版前確認已足夠讓人
  自己決定。可日後疊加。
- **延長續期逾時**：短睡不丟、長睡還是丟，別人要等更久才能接手；治標。
- **author 改成草稿作者**：按下進版、對整批負責的是進版者；而且一批可有多位草稿作者，
  git 只有一個 author。
- **用 git 的 `Co-authored-by:` trailer**：語意接近，但本 repo 以 #269 禁止該 trailer（避免工具
  帳號進 Contributors），用在真人身上容易與那條規則混淆；而且 GitHub 不會顯示 config repo 的
  紀錄，trailer 的好處用不到。改用與 `override(...)` 行同形的內文行，`history` 端點照樣撈。
- **以姓名＋email 當同一人**：冒名即視為同一人，使用者否決。
- **只用票**：不可讀。

## Consequences

- `Draft` 多 `saved_by`／`touched_by`；`save_draft`／`adopt_draft` 收儲存者。
- 取得編輯階段的回應多 `kept_drafts`（接手到的、不是自己的）；`cleared_drafts` 只剩閒置逾時會記。
- 退出的 `confirm_required` 逐人列（`by_owner`、`distinct`）。
- `POST /api/promote` 可帶 `expected`（確認當下的草稿簽章），不符 409 `drafts_changed`。
- `history` 回 `drafted_by`；紀錄內文多 `drafted-by:` 行（只在作者 ≠ 進版者時）。
- 頁面：草稿標記帶最後儲存者、可開完整參與者名單（鍵盤與觸控也能開）；接手橫幅；進版前的條件確認；
  續期 410 的唯讀橫幅說草稿還在不在（依實際狀態）；退出確認逐人；歷史列「含〈誰〉存的草稿」。
- ADR-00000014 Consequences「部署模式下閒置 10 分鐘自動退出並釋放階段」不變，補「續期逾時不清草稿」；
  ADR-00000022 Consequences「階段逾時釋放時草稿一併清除，必須明確提示」改為只限閒置逾時與退出。
  兩份原文保留、加註被本 ADR 取代的那一句。
