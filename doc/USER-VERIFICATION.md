# 使用者功能驗證清單

這份清單帶你實際操作，確認功能是否完成。程式存在、按鈕存在或開發者說完成，都不等於驗證通過。給 Claude 的修正規則見 [開發者驗證與修正清單](CLAUDE-VERIFICATION.md)。

## 使用方式

1. 先請 Claude 準備下面的測試環境與資料，填好網址及路徑。
2. 從 U01 開始，一項一項操作；每項都符合「應看到的結果」才勾選。
3. 找不到功能，填「未完成」；操作結果不對，填「失敗」；環境或前置功能不具備，填「阻擋」。三者都保持未勾選。
4. 把項目編號、操作與看到的現象交給 Claude。修正後重做原項目，再由你決定是否勾選。

每項結果可填：`通過／失敗／未完成／阻擋／未測`。空白一律代表未測，不代表通過。

**本表是操作用驗收單，不是最新實作進度表。** 起始提示（2026-09-22，僅靜態核對）：目前主要可操作的是身分、清單、納管、格式檢視、白名單和狀態掃描；參數編輯、進版、退版等後續流程仍不完整。執行當天由 Claude 依程式、[測試計畫](TEST-PLAN.md)與實際操作重新確認，所有勾選預設留空。

涉及檔案內容、Git 歷史、權限等畫面外資訊時，請 Claude 提供前後比較證據，你核對結果即可。表內「請 Claude」的步驟是安排測試情境；一般納管與編輯操作仍應由你從介面完成。
