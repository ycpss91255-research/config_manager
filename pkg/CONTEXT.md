# CONTEXT — 領域用語

固定用語表。**寫程式碼、文件、變更紀錄、介面文案時一律採用此處的說法**，
不重新造詞。新增術語時更新此檔。

---

## 核心名詞

| 中文 | 英文 / 識別碼 | 意義 |
|---|---|---|
| 來源 repo | `config-repo` | 存放所有被管理 config 內容的 git repo。系統認定它是唯一正確的版本 |
| 目標位置 | `target` | config 實際被程式讀取的路徑。內容由系統寫出，非權威 |
| config 清單檔 | `config-list.toml` | 記錄「管了哪些 config、各自的目標位置與權限」的檔案 |
| 納管 | `import` | 把一份已存在於磁碟的 config 納入管理。過程不改變檔案內容 |
| 解除納管 | `unmanage` | 停止管理。**目標檔案保留**，系統不再追蹤 |
| 寫出 | `apply` | 把來源 repo 的內容寫到目標位置並設定權限 |
| 草稿 | `draft` | 已在介面編輯但尚未進版的內容。存於編輯階段，不在來源也不在目標 |
| 進版 | `promote` | 把全部草稿一次驗證、記錄、寫出。**全域動作** |
| 退版 | `revert` | 回復到先前版本。以反向變更實作，不改寫歷史 |
| 納入 | `adopt` | 把目標位置的現況收回來源 repo |
| 原樣解析 | round-trip | 改動一個值，其餘註解、引號樣式、順序原封不動 |

## 狀態

| 中文 | 識別碼 | 判定 |
|---|---|---|
| 未納管 | `unmanaged` | 不在清單檔中 |
| 一致 | `in_sync` | 目標內容 == 來源內容 |
| 偏離 | `drift` | 目標內容 != 來源內容。**代表有人繞過介面直接修改** |
| 未部署 | `missing` | 目標檔案不存在 |

**「偏離」是唯一的異常狀態**，其餘三種都是正常流程中的合法狀態。

**草稿不是第五種狀態**——四種狀態比較的是目標與來源，草稿與之正交。

## 身分欄位

| 欄位 | 誰產生 | 會不會變 | 用途 |
|---|---|---|---|
| `uid` | 系統，由匯入時刻的毫秒時間戳轉 base36 | **永不變** | 唯一的真實識別碼。所有內部關聯只認它 |
| `name` | 從目標路徑推導，人可改 | 可改 | 給人看。過期也不影響任何功能 |
| `hostname` | 納管時讀系統 hostname 寫入檔案，人可改 | 可改 | 實例維度。跨機比對時以 `name` 分組 |

完整參照形式：`<name>@<hostname>-<uid>`，例如 `navigation-params@amr01-mfz3k9q1`。

## 角色與環境

| 概念 | 值 | 誰決定 | 影響 |
|---|---|---|---|
| 角色 | 一般使用者 / 開發者 | 使用者於身分輸入時選擇 | **能做什麼**（型別指定、白名單、屬性編輯限開發者） |
| 環境 | 開發 / 部署 | backend 依部署階段判定 | **階段行為**（記住裝置、閒置逾時） |

兩者正交。介面上僅開發者可用的元素標記 🔧，且一般使用者模式下**直接不顯示**而非停用。

## 驗證層級

| 層 | 檢查什麼 | 處置 |
|---|---|---|
| 第 1 層 | 語法、正規形式白名單、重複 key | 硬擋 |
| 第 2 層 | 型別、必填、數值範圍（依 schema） | 硬擋 |
| 第 3 層 | 跨欄位規則、外部一致性 | 警告 + 可 override |

## 變更紀錄類型

`import` / `cfg` / `revert` / `adopt` / `meta` / `unmanage`。
格式 `<類型>(<uid>): <說明>`，範圍只放 `uid`（`name` 與 `hostname` 會改）。

**介面上不顯示這些代號**，顯示對應的行為描述：納入管理／修改參數／退回舊版本／
採納現場調整／調整設定／解除管理。

## 測試用語

| 中文 | 意義 |
|---|---|
| 測試介面 | 從哪個位置觀察行為。測試寫在公開介面上，不寫在內部實作上 |
| 驗收旅程 | 完整的使用者旅程，以使用者的語言描述目標 |
| 刻意留空 | 沒有測試介面覆蓋、但**寫下了理由**的位置。沒寫理由的就是漏掉 |

## 避免使用的說法

| 不用 | 用 | 原因 |
|---|---|---|
| manifest | config 清單檔 | 中文語境下不明確 |
| DRIFT / IN SYNC / MISSING | 偏離 / 一致 / 未部署 | 介面與文件一律中文 |
| 進板 / 退板 | 進版 / 退版 | 版＝version，板＝board |
| 登入 / 登出 | 身分輸入 / 退出 | 沒有認證機制，說「登入」「登出」會誤導 |
| 線上編輯器 | 參數欄位表 | 使用者不編輯檔案文字 |
| seam | 測試介面 | 外來詞，中文講得清楚，不需增加查詢成本 |
